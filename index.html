The Pumping Lemma Interactive Game

Pumping Lemma for Regular Languages: If \(L\) is a regular language, then there exists an integer \(p \geq 1\), called the pumping length, such that every string \(s \in L\) with \(|s| \geq p\) can be written as \(s = xyz\), satisfying the following conditions:

  1. \(|xy| \leq p\)
  2. \(|y| \geq 1\)
  3. For every integer \(i \geq 0\), \(xy^iz \in L\)

Goal: Prove $L$ is NOT regular by finding a contradiction!

Step 1

Choose Language to Disprove

Step 2

Adversary Chooses $p$

Step 3

You Choose String $s \in L$ ($|s| \ge p$)

Step 4

Adversary Decompositions ($s = xyz$)

Step 5

You Choose Pump $i \ge 0$ to Break Condition

Choose $i$ and test if pumped string violates the language definition.

Theory of Computation Studio — Help & User Guide

🎨 Interactive Canvas Controls

  • Add State: Select "Add State" tool and click anywhere on the canvas.
  • Add Transition: Select "Transition" tool, click and drag from source state to target state. Self-loops are supported!
  • Set Initial State: Select "Initial" tool and click a state.
  • Toggle Final / Accepting: Select "Final" tool and click a state (double ring ◎).
  • Pan & Zoom: Hold middle click or Space+Drag to pan. Use mouse wheel to zoom.

📐 Theory of Computation Modules

  • Finite Automata: DFA, NFA, ε-NFA simulation with step tracer and batch testing.
  • Conversions: NFA→DFA (Subset construction), DFA Minimization, FA→Regex, Regex→NFA, Grammar↔FA.
  • Transducers: Mealy and Moore machine simulation and bidirectional converter.
  • PDA: Pushdown Automata with animated stack container and ID trace.
  • CFG & Parsing: FIRST/FOLLOW sets, LL(1) parse table, SLR(1) items & table, CNF 5-step pipeline.
  • Turing Machines: Single-Tape and 2-Tape machines with endless ribbon visualizer.
  • Pumping Lemma Lab: Interactive adversarial game for regular and context-free languages.
  • L-Systems: Parallel grammar expansion with 2D turtle graphics.
